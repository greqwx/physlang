## physlang
Простой интерпретатор, для решения задач по физике.<br>
Сделан как учебный пет-проект, код под unlicense, делайте с ним что хотите.

```
[----Дано----]
t = 5 сек
u = 72 км/ч
u0 = 0
--------------
[----Найти---]
a - ?
--------------
```
Пример задачи. Эта задача решается через `./physlang exercise.ph`<br>
Вывод, который должен выдать интерпретатор:
```
Дано:        | СИ | Решение
u0 = 20 м/с  |    | a = (u^2 - u0^2)/(2*s)
u = 0        |    | a = (0^2 - 20^2)/(2*50)
s = 50 м     |    | a = -4 м/с²
-------------+----+-------------------------
a - ?        |    |

Ответ: a = -4 м/с²
```

### Собрать из исходников
```sh
go build .
```
Если будете переносить бинарник, не забудьте formulas.txt положить рядом с ним.
